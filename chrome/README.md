# MyPLaMo ページ翻訳

Webページの選択した文章やページ全体を、PC内のモデルで翻訳するChrome拡張機能です。アイコンをクリックすると翻訳・設定メニューが開きます。Built with PLaMo。

## 必要なもの

- Google Chrome 116以降
- 新しい言語・文体・用語集・文脈の設定：Windows版MyPLaMo 1.4.0以降、またはMyPLaMo for Mac 0.3.0以降
- 基本の日本語翻訳：Windows版MyPLaMo 1.1.0以降、またはMyPLaMo for Mac 0.2.0以降。旧本体に対応しない設定を選ぶと、更新の案内を表示します。
- 本体でダウンロード・選択した翻訳モデル

この拡張は本体と連携して動作します。拡張単体では翻訳できません。

## インストール

1. 拡張機能の配布ZIPを展開します。
2. Chromeで `chrome://extensions` を開き、デベロッパーモードをオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」から、展開したフォルダ内の `extension` を選びます。リポジトリから取得した場合は `chrome/extension` を選んでください。
4. 翻訳するサイトへのアクセスを許可し、Webページを再読み込みします。
5. MyPLaMo本体を起動してモデルを選び、「Chromeからの翻訳を受け付ける」をオンにします。

Mac版の受付スイッチは本体を起動するたびにオフになります。利用するときにオンにしてください。

## 選択した文章を翻訳

Webページの文章をマウスまたはキーボードで選択すると、そばにMyPLaMoアイコンが表示されます。クリックすると訳文のポップアップが開きます。

- 右上のクリップボードアイコンで訳文をコピーできます。コピーするとチェックマークに変わります。
- 上段に、接続した本体のバージョンを表示します。
- ×・Escape・ポップアップの外側のクリックで閉じられます。
- スクロールやウィンドウサイズの変更でも閉じます。
- 翻訳先・用語集・サイト別文体は拡張の設定に従います。1回の選択は2,000文字までです。
- 文章を選択しただけでは翻訳を開始せず、ページ本文も書き換えません。

入力欄や編集領域、埋め込みフレーム、PDF、Chrome内部ページなどは対象外です。

## ページ全体を翻訳

ツールバーの拡張アイコンからメニューを開き、原語・訳語・用語集を選んで「このページを翻訳」を押します。ページ上で右クリックし「MyPLaMoでWEB全体を翻訳」からも開始できます。本文・リンク・ボタン・後から追加された文章を翻訳します。

右下、またはメニューの「原文に戻す」で元に戻ります。翻訳した文字にマウスを重ねると、その箇所の原文を確認できます。余白では原文を表示しません。

PDF、画像内の文字、埋め込みフレーム、コード、入力欄、Chrome内部ページなどは対象外です。

## 接続先と翻訳設定

本体で選択したモデル・GPUを使用し、本体と拡張からの依頼を順番に処理します。言語・用語集・文体は拡張側で選べます。用語集の作成・編集は本体の「用語集」で行います。翻訳中は本体を起動したままにしてください。

本体が起動していない、または受付スイッチがオフのときは、拡張アイコンの右下に黄色い丸の「！」を表示します。未接続でも設定メニューは利用できます。接続状態は約1分ごとに自動確認し、メニューを開いたときや翻訳操作時にも確認します。本体への接続が戻ると通常のアイコンに戻ります。

## メニューの設定

- **翻訳**：原語の自動検出または言語指定、訳語、用語集、自動翻訳、原文ホバー表示、選択時の翻訳ボタン表示を設定します。自動翻訳は初期状態でオフです。
- **自動翻訳フィルター**：除外リスト・許可リストを選び、現在のページ・サイトまたは `https://example.com/*` のようなURLパターンを追加・検索・削除できます。`*` は任意の文字列に一致します。手動翻訳には影響しません。
- **文体制御**：標準は「です・ます」調です。「だ・である」調にするURLを登録・検索・削除できます。日本語への翻訳に適用します。
- **キャッシュ**：保存した翻訳のページ数・容量・期間を表示します。URL検索・ページ単位の削除・全件削除が可能です。最大100ページ・約6MBで、古いページから自動削除します。言語・文体・用語集・モデルが異なる翻訳は別に保存します。
- **表示設定**：改行・折り返しの自動調整、マウスが離れたときの原文非表示、翻訳中の背景色を設定します。原文はクリック・Escapeでも閉じられます。

設定は自動で保存されます。表示設定は開いているページにも反映します。翻訳方向・用語集・文体を変えた場合は「このページを翻訳」で再翻訳してください。

対応する本体では、翻訳時に本体のバージョンを表示します。表示は最後の翻訳応答時点の情報です。旧本体では「バージョン未確認」と表示しますが、翻訳は引き続き利用できます。

互換性に関する案内が出た場合は、本体と拡張の両方を更新してください。

## 更新方法

1. 新しい配布ZIPを展開し、使用中の拡張フォルダを更新します。
2. `chrome://extensions` でMyPLaMo ページ翻訳の再読み込みボタンを押します。
3. 翻訳したいWebページも再読み込みします。

サイトへのアクセス許可を求められた場合は、内容を確認して許可してください。選択アイコンを表示するには、そのサイトへのアクセスが必要です。

## うまく動かない場合

- **本体に接続できない：** 本体が起動しているか、受付スイッチがオンか確認してください。
- **翻訳されない：** 本体でモデルをダウンロード・選択しているか確認してください。
- **選択アイコンが出ない：** サイトへのアクセス許可と、Webページの再読み込みを確認してください。入力欄やChrome内部ページなどでは表示されません。
- **更新後も古い表示になる：** 拡張機能とWebページの両方を再読み込みしてください。

## プライバシーとライセンス

翻訳は同じパソコン上のMyPLaMo本体で処理します。原文・訳文を外部の翻訳APIへ送信しません。設定と翻訳キャッシュ（原文、参照する文脈、訳文、URLを含む）はChromeのローカルストレージに保存します。キャッシュはメニューから削除できます。
