# MyPLaMo ページ翻訳 2.2.0

Windows版MyPLaMo 1.1.0以降、またはMyPLaMo for Mac 0.2.0以降のオプション機能です。Built with PLaMo。

1. 本体を起動して取得済みモデルを選び、「Chromeからの翻訳を受け付ける」をオンにします。
2. Chromeの `chrome://extensions` でデベロッパーモードをオンにし、「パッケージ化されていない拡張機能を読み込む」で `extension` フォルダーを選びます。
3. ページ上の右クリックから「MyPLaMoでWEB全体を翻訳」、または拡張アイコンを押します。本文・リンク・ボタン・後から追加された文章が日本語になります。
4. 右下の「原文に戻す」、または拡張アイコンで元に戻します。

本体のモデル・GPU・文体設定を使い、本体と同じエンジンで順番に処理します。PDF、画像内の文字、埋め込みフレーム、コード、入力欄は対象外です。専用の連携アプリやNative Messaging登録は不要です。

更新時は既存の展開先に上書きして、拡張機能管理画面で再読み込みしてください。拡張ID `oefekpcnnmijlldkpeplijencgdnakbb`、`ws://127.0.0.1:47832/translate`、JSON通信形式を維持しています。WindowsとMacのどちらでも同じ拡張を使用します。

旧版の専用連携アプリが動作している場合は終了し、本体を更新してください。Macでは受付スイッチはアプリ起動ごとにオフになります。

Mac上で実ページの翻訳・動的追加・原文復帰を検証済みです。2.1.2は利用者によりWindows実機で翻訳確認済みです。2.1.3の表示機能とWindows本体の情報応答追加は実機未検証です。ソースのライセンスはLICENSE-MITを参照してください。


### 接続先表示（拡張2.1.3）

翻訳応答を受信すると、ページ右下に本体の種類とバージョンを表示します。Mac版0.2.1以降、および情報応答を追加したWindows版に対応します。表示は最後の翻訳応答時点の接続先で、常時接続を監視するものではありません。

旧本体は「本体情報非対応の旧版・バージョン未確認」と表示し、従来どおり翻訳します。OSを推測して表示することはありません。通信バージョンが一致しない場合は訳文を適用せず、両方の更新を案内します。本体の製品バージョンの違いだけでは翻訳を拒否しません。


## 選択した文章を翻訳（2.2.0）

Webページの文章をマウスまたはキーボードで選択すると、選択範囲のそばにMyPLaMoアイコンが表示されます。アイコンをクリックすると訳文のポップアップが開きます。「コピー」で訳文をコピーでき、×・Escape・外側のクリックで閉じられます。ページ本文は変更しません。

翻訳先は日本語、1回の選択は2,000文字以内です。選択だけでは翻訳を依頼しません。本体の受付スイッチ・選択モデル・文体はページ全体の翻訳と共通です。入力欄・編集領域、埋め込みフレーム、PDF、Chrome内部ページは対象外です。スクロール・ウィンドウサイズ変更でポップアップを閉じます。

更新後はChromeの拡張管理画面で再読み込みし、翻訳したいWebページも再読み込みしてください。選択を自動検出するため、HTTP/HTTPSページで動くcontent scriptを追加しています。Chromeでサイトへのアクセス許可が必要です。これまでのactiveTabによる操作時のみのアクセスから、許可されたサイトで選択を検出する方式になります。

検証：選択表示・クリック時のみ依頼・コピー・閉じる・長文制限・接続エラー・遅延応答の破棄・編集領域除外を自動テスト。Chrome実画面では表示テスト用の応答でポップアップとコピーを確認しました。2.2.0のWindows実機確認は未実施です。

開発テスト：このchromeフォルダで `npm ci` の後に `npm test`。表示確認用ページは親フォルダをローカルHTTP配信して `Tests/web/selection-preview.html` を開きます（固定のテスト応答です）。
