# MyPLaMo ページ翻訳 2.1.2

Windows版MyPLaMo 1.1.0以降、またはMyPLaMo for Mac 0.2.0以降のオプション機能です。Built with PLaMo。

1. 本体を起動して取得済みモデルを選び、「Chromeからの翻訳を受け付ける」をオンにします。
2. Chromeの `chrome://extensions` でデベロッパーモードをオンにし、「パッケージ化されていない拡張機能を読み込む」で `extension` フォルダーを選びます。
3. ページ上の右クリックから「MyPLaMoでWEB全体を翻訳」、または拡張アイコンを押します。本文・リンク・ボタン・後から追加された文章が日本語になります。
4. 右下の「原文に戻す」、または拡張アイコンで元に戻します。

本体のモデル・GPU・文体設定を使い、本体と同じエンジンで順番に処理します。PDF、画像内の文字、埋め込みフレーム、コード、入力欄は対象外です。専用の連携アプリやNative Messaging登録は不要です。

更新時は既存の展開先に上書きして、拡張機能管理画面で再読み込みしてください。拡張ID `oefekpcnnmijlldkpeplijencgdnakbb`、`ws://127.0.0.1:47832/translate`、JSON通信形式を維持しています。WindowsとMacのどちらでも同じ拡張を使用します。

旧版の専用連携アプリが動作している場合は終了し、本体を更新してください。Macでは受付スイッチはアプリ起動ごとにオフになります。

Mac上で実ページの翻訳・動的追加・原文復帰を検証済みです。Windows実機での今回の更新の動作確認は未実施です。ソースのライセンスはLICENSE-MITを参照してください。
