# MyPLaMo for Mac

PLaMo 3 Translateの公式MLXモデルを使用するmacOS用翻訳アプリです。
Built with PLaMo。

## 動作条件

- Apple Silicon搭載Mac
- macOS 27.2以降
- モデルの取得に必要なインターネット接続と空き容量

モデル取得後の翻訳はMac内で処理します。原文・訳文を外部の翻訳APIへ送信しません。

## インストールと初回起動

1. 同梱の「MyPLaMo for Mac.app」をアプリケーションフォルダなどに移動します。
2. アプリを起動します。
3. 「モデル」ボタンからモデルの保存先を指定し、利用条件を確認してモデルをダウンロードします。
4. ダウンロードしたモデルを選択します。

モデルはこのZIPに含まれていません。Pythonなどの追加インストールは不要です。

この配布アプリにはDeveloper ID署名・Apple公証を行っていないため、macOSのセキュリティ機能によって起動が制限される場合があります。

## 翻訳する

原文を入力または貼り付け、翻訳元・翻訳先の言語を選んで「翻訳する」を押します。⌘Returnでも開始できます。翻訳元は自動検出も利用できます。

- 53言語に対応し、原文は1回6,000文字まで入力できます。
- 日本語への翻訳では「です・ます」「だ・である」を選べます。
- 通常のテキスト翻訳では結果を順次表示し、途中で中止できます。
- 「コピー」で訳文をコピーできます。
- 翻訳結果が出力上限に達した場合は、文章を短く分けて翻訳してください。

ウィンドウを閉じてもアプリは常駐します。再表示や終了はメニューバーから行えます。

## 用語集を使う

「用語集を管理…」で用途ごとの用語集を作り、原語・訳語・翻訳元言語・翻訳先言語を登録できます。検索、名前変更、用語の編集・削除にも対応します。翻訳画面の「用語集」から使用するものを選んでください。「用語集なし」も選べます。

登録した翻訳方向と一致し、文章に含まれる用語だけをモデルへの指示に使います。訳語が必ず採用されるとは限りません。

用語集は100件、各5,000語までです。名前は80文字、原語・訳語は各200文字まで登録できます。一度の翻訳部分に一致する用語が32語または原語・訳語の合計2,000文字を超える場合は、文章を短く分けてください。

### バックアップ・復元

用語集の管理画面の「バックアップ」で、**保存済みの全用語集**を `.myplamo-glossary` ファイルに保存できます。検索結果や選択中の1件に限定されません。編集中でまだ保存していない名前・用語は含まれないため、必要な変更は先に保存してください。用語が0語の用語集も保存できます。

「復元」でファイルを選ぶと、追加する用語集・用語の件数と、同じ内容のためスキップする件数を確認できます。「追加して復元」を押すまで現在のデータは変わりません。現在の用語集は残り、同じ名前でも内容が異なる場合は別の用語集として追加します。同じ内容を再び復元しても重複して増えません。翻訳に使用中の用語集は切り替わりません。

Windows版の同機能と共通の専用形式で、用語集名・原語・訳語・翻訳方向をまとめて保存します。ファイルの上限は128MiBで、展開後のデータも128MiB以下です。復元後も用語集100件・各5,000語の上限が適用されます。このファイルは暗号化されていません。手編集やCSVとしての読み込みには対応していません。

## 文脈を考慮する

「文脈を考慮」は初期状態でオンです。長い文章を分けて翻訳するとき、直前の原文・訳文を参考にします。話題や用途などを補う場合は「参照する文脈」に800文字まで入力できます。

オフにすると参照文脈と直前の翻訳を追加せずに処理します。直前の原文・訳文は、1回の翻訳処理内だけで使います。

## 文書の構造を保って翻訳する

原文欄へ文章を貼り付け、「形式」で「自動判定」「テキスト」「Markdown」「JSON」「YAML」を選びます。自動判定が意図と異なる場合は、形式を指定してください。原文全体の上限は6,000文字です。

- テキスト：改行・段落・前後の空白を保持します。
- Markdown：文章を翻訳し、見出し・表・リンク等の記法、コード、リンク先、先頭の設定部分を保持します。
- JSON：自然言語を含む文字列値を翻訳し、キー・数値・真偽値・URL・字下げ等を保持します。
- YAML：自然言語の値を翻訳し、キー・コメント・字下げ・型・URL等を保持します。タグ・アンカー・エイリアス付きの値は変更しません。

JSON・YAMLを指定した場合、構文に問題がある入力はエラーとして案内します。文書の翻訳は完了後に元の構造へ組み立てて表示します。Word・PDF・画像のファイルを読み込む機能ではありません。

## モデルと設定

0.8B / 2B / 8B / 31BのMLX-4bitモデルを選択できます。ダウンロード容量の目安は、それぞれ約0.98 / 2.41 / 6.07 / 18.66 GBです。実行時には追加のメモリが必要なため、Macのメモリ容量に合わせて選んでください。

保存先の変更、外部ドライブへの保存、ダウンロードの一時停止・再開、モデルの移動に対応します。標準ではApple GPUを使用し、設定からCPUに切り替えられます。

履歴保存は初期状態でオフです。有効にすると最大100件を使用中のMacに保存します。設定から保存の無効化や履歴の削除ができます。

⌥⌘Tでアプリを呼び出せます。設定でT / Y / Jを選択できます。他のアプリから選択文を取得する場合は、macOSのアクセシビリティ許可が必要です。手動貼り付けは許可不要です。「元のアプリへ挿入」は確認後に現在の挿入位置へ貼り付けます。

## ChromeでWeb翻訳

Windows版と共通の「MyPLaMo ページ翻訳」拡張機能を別途利用できます。拡張はこのZIPには含まれていません。新しい言語・用語集・文脈などの設定にはMac本体0.3.0以降を使用してください。

本体を起動し、モデルを選択して「Chromeからの翻訳を受け付ける」をオンにしてください。受付は本体を起動するたびにオフになります。

ツールバーの拡張アイコンを押すと、翻訳・設定メニューが開きます。

- 原語・訳語・用語集を選び、「このページを翻訳」でページ全体を翻訳します。ページ上の右クリックからも開始できます。
- ページ右下またはメニューの「原文に戻す」で元に戻せます。
- 文章を選択してそばのMyPLaMoアイコンをクリックすると、訳文とコピーボタンを表示します。言語・用語集・サイト別文体は拡張の設定に従い、選択は2,000文字までです。
- 自動翻訳と対象サイトのフィルター、日本語のサイト別文体、原文ホバー表示、改行・背景色などを設定できます。自動翻訳は初期状態でオフです。
- 「キャッシュ」では保存された翻訳をURLで検索し、ページ単位または全件を削除できます。

本体未起動または受付オフでは、アイコン右下に黄色い丸の「！」を表示します。未接続でも設定メニューは利用できます。拡張の更新後は、拡張機能管理画面とWebページの両方を再読み込みしてください。

詳しい導入・更新方法は、同梱の「Chrome拡張の使い方.md」を参照してください。

## 保存データとプライバシー

用語集と選択設定はMac内に保存します。任意の参照文脈の本文は本体の設定や履歴には保存しません。翻訳中の直前ペアは1回の翻訳処理内だけで使い、次の翻訳依頼へ持ち越しません。

Chrome拡張の設定と翻訳キャッシュは、Chromeのローカルストレージ（storage.local）に保存します。キャッシュには原文・訳文・参照文脈・URLを含みます。最大100ページ・約6MBで古いページから削除し、言語・文体・用語集・モデル等が異なる結果は使い回しません。

キャッシュは拡張メニューから削除できます。本体の履歴保存がオフでも、拡張のキャッシュは別に保存されます。拡張からの翻訳で本体の入力欄・翻訳結果・履歴を書き換えることはありません。
