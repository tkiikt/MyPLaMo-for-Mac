# MyPLaMo for Mac

PLaMo 3 Translateの公式MLXモデルを使用するmacOS用翻訳アプリです。
Built with PLaMo。

## 動作条件

- Apple Silicon搭載Mac
- macOS 27.2以降
- モデルの取得に必要なインターネット接続と空き容量

モデル取得後の翻訳はMac内で処理します。原文・訳文を外部の翻訳APIへ送信しません。

## インストールと初回起動

1. 同梱の「MyPLaMo for Mac.app」をアプリケーションフォルダなどに移動します。
2. アプリを起動します。
3. 「モデル」ボタンからモデルの保存先を指定し、利用条件を確認してモデルをダウンロードします。
4. ダウンロードしたモデルを選択します。

モデルはこのZIPに含まれていません。Pythonなどの追加インストールは不要です。

この配布アプリにはDeveloper ID署名・Apple公証を行っていないため、macOSのセキュリティ機能によって起動が制限される場合があります。

## 翻訳する

原文を入力または貼り付け、翻訳元・翻訳先の言語を選んで「翻訳する」を押します。⌘Returnでも開始できます。翻訳元は自動検出も利用できます。

- 53言語に対応し、原文は1回6,000文字まで入力できます。
- 日本語への翻訳では「です・ます」「だ・である」を選べます。
- 翻訳中は結果を順次表示し、途中で中止できます。
- 「コピー」で訳文をコピーできます。
- 翻訳結果が出力上限に達した場合は、文章を短く分けて翻訳してください。

ウィンドウを閉じてもアプリは常駐します。再表示や終了はメニューバーから行えます。

## モデルと設定

0.8B / 2B / 8B / 31BのMLX-4bitモデルを選択できます。ダウンロード容量の目安は、それぞれ約0.98 / 2.41 / 6.07 / 18.66 GBです。実行時には追加のメモリが必要なため、Macのメモリ容量に合わせて選んでください。

保存先の変更、外部ドライブへの保存、ダウンロードの一時停止・再開、モデルの移動に対応します。標準ではApple GPUを使用し、設定からCPUに切り替えられます。

履歴保存は初期状態でオフです。有効にすると最大100件を使用中のMacに保存します。設定から保存の無効化や履歴の削除ができます。

⌥⌘Tでアプリを呼び出せます。設定でT / Y / Jを選択できます。他のアプリから選択文を取得する場合は、macOSのアクセシビリティ許可が必要です。手動貼り付けは許可不要です。「元のアプリへ挿入」は確認後に現在の挿入位置へ貼り付けます。

## ChromeでWeb翻訳

別途配布する「MyPLaMo ページ翻訳」拡張機能を利用できます。拡張はこのZIPには含まれていません。

本体を起動し、モデルを選択して「Chromeからの翻訳を受け付ける」をオンにしてください。受付は本体を起動するたびにオフになります。

- Webページの文章を選択し、MyPLaMoアイコンをクリックすると訳文とコピーボタンを表示します。
- ページ上の右クリックから「MyPLaMoでWEB全体を翻訳」を選ぶと、ページ全体を日本語に翻訳します。
- 「原文に戻す」または拡張アイコンで元に戻せます。

拡張の導入・更新方法は、同梱の「Chrome拡張の使い方.md」を参照してください。
