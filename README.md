# MyPLaMo for Mac

PLaMo 3 Translateの公式MLX-4bitモデルを使う、SwiftUI / AppKit製のmacOSネイティブ翻訳アプリです。Built with PLaMo。モデル取得後の翻訳はMac内で完結します。

## 起動と翻訳

`MyPLaMo for Mac.app` を開いてください。現在のビルドはApple Silicon / macOS 27.2以降用です。

モデルはアプリの「モデル」ボタンから取得・選択してください。モデルは配布ZIPに含めていません。

- 原文を入力して「翻訳する」、または ⌘Return。53言語、言語自動判定、日本語の敬体・常体、逐次表示、中止に対応。
- ⌥⌘Tで呼び出せます。設定でT / Y / Jを選択できます。
- 選択文の取得はmacOSのアクセシビリティ許可が必要です。手動貼り付けは許可不要です。
- メニューバーから再表示・クリップボード翻訳・終了ができます。ウィンドウを閉じても常駐します。
- 「元のアプリへ挿入」は確認後に現在の挿入位置へ貼り付けます。

## 動作条件とインストール

- Apple Silicon搭載Mac
- macOS 27.2以降
- モデルの取得に必要なインターネット接続と空き容量
- Web翻訳を利用する場合はGoogle Chrome

配布DMGを開き、`MyPLaMo for Mac.app` を右側の「Applications（アプリケーション）」へドラッグしてください。コピー完了後はDMGを取り出し、アプリケーションフォルダから起動します。使い方とライセンスはDMG内の「使い方とライセンス」フォルダに同梱しています。モデルは別途、アプリ内から取得します。

配布アプリにはDeveloper ID署名・Apple公証を行っていないため、macOSのセキュリティ機能によって起動が制限される場合があります。

## モデル

公式のPLaMo 3 Translate MLX-4bitモデルを使用します。

| モデル | ダウンロード容量の目安 |
| --- | --- |
| 0.8B | 約0.98 GB |
| 2B | 約2.41 GB |
| 8B | 約6.07 GB |
| 31B | 約18.66 GB |

実行時にはモデルの保存容量とは別にメモリが必要です。使用するMacのメモリ容量に合わせて選んでください。

保存先の変更、外部ドライブへの保存、ダウンロードの一時停止・再開、モデルの移動に対応します。ダウンロードしたファイルは整合性を確認してから使用します。

モデルは同時に1つだけ読み込みます。標準ではApple GPUを使用し、設定からCPUに切り替えられます。原文は1回6,000文字まで入力できます。翻訳結果が出力上限に達した場合は、文章を短く分けて翻訳してください。

モデルの利用条件は、ダウンロード画面のPLaMo Community Licenseを確認してください。

## ChromeでWeb翻訳

Windows版MyPLaMoと共通の拡張機能「MyPLaMo ページ翻訳」を利用できます。本体で選択したモデル・GPU・文体設定を使用します。

### 拡張機能の追加

1. 本体を起動してモデルを選び、「Chromeからの翻訳を受け付ける」をオンにします。
2. 拡張機能の配布ZIPを展開します。
3. Chromeで `chrome://extensions` を開き、デベロッパーモードをオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」から、展開したフォルダ内の `extension` を選びます。リポジトリから取得した場合は `chrome/extension` を選んでください。
5. 翻訳するサイトへのアクセスを許可し、Webページを再読み込みします。

Mac版の受付スイッチは本体を起動するたびにオフになります。利用するときにオンにしてください。

### 選択した文章を翻訳

Webページの文章を選択し、そばに表示されるMyPLaMoアイコンをクリックすると、訳文のポップアップが開きます。「コピー」で訳文をコピーできます。×・Escape・ポップアップの外側のクリックで閉じられます。

翻訳先は日本語、1回の選択は2,000文字までです。文章を選択しただけでは翻訳を開始せず、ページ本文も書き換えません。入力欄や編集領域は対象外です。

### ページ全体を翻訳

ページ上で右クリックして「MyPLaMoでWEB全体を翻訳」を選ぶか、ツールバーの拡張アイコンを押します。本文・リンク・ボタン・後から追加された文章を日本語に翻訳します。「原文に戻す」または拡張アイコンで元に戻せます。

PDF、画像内の文字、埋め込みフレーム、コード、入力欄、Chrome内部ページなどは対象外です。

### 更新と接続の案内

拡張を更新したら、拡張機能管理画面と翻訳したいWebページの両方を再読み込みしてください。

対応する本体では、翻訳時に接続先の種類とバージョンを表示します。旧本体では「バージョン未確認」と表示しますが、翻訳は引き続き利用できます。互換性に関する案内が出た場合は、本体と拡張の両方を更新してください。

詳しくは [拡張機能のREADME](chrome/README.md) を参照してください。

## 設定とプライバシー

モデル取得後の翻訳はMac内で処理し、原文・訳文を外部の翻訳APIへ送信しません。モデル情報の取得とダウンロードにはHugging Faceへの通信を使用します。

履歴保存は初期状態でオフです。有効にすると最大100件を使用中のMacに保存します。設定から保存の無効化や履歴の削除ができます。

Chrome拡張は本体が起動し、受付スイッチがオンの間だけ利用できます。拡張からの翻訳で、本体の入力欄・翻訳結果・履歴は書き換えません。
