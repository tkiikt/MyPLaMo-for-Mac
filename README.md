# MyPLaMo for Mac

PLaMo 3 Translateの公式MLX-4bitモデルを使う、SwiftUI / AppKit製のmacOSネイティブ翻訳アプリです。Built with PLaMo。モデル取得後の翻訳はMac内で完結します。

Windows版は [MyPLaMo](https://github.com/tkiikt/MyPLaMo)

## ダウンロード

[最新版のダウンロード](https://github.com/tkiikt/MyPLaMo-for-Mac/releases/latest)

- **MyPLaMo-for-Mac-arm64.dmg**：Mac用アプリ（README・ライセンス同梱）
- **MyPLaMo-Web.zip**：Windows・Mac共通のChrome拡張

## 起動と翻訳

`MyPLaMo for Mac.app` を開いてください。現在のビルドはApple Silicon / macOS 27.2以降用です。

モデルはアプリの「モデル」ボタンから取得・選択してください。モデルは配布ファイルに含めていません。

- 原文を入力して「翻訳する」、または ⌘Return。53言語、言語自動判定、日本語の敬体・常体、進捗表示、中止に対応。
- ⌥⌘Tで呼び出せます。設定でT / Y / Jを選択できます。
- 選択文の取得はmacOSのアクセシビリティ許可が必要です。手動貼り付けは許可不要です。
- メニューバーから再表示・クリップボード翻訳・終了ができます。ウィンドウを閉じても常駐します。
- 「元のアプリへ挿入」は確認後に現在の挿入位置へ貼り付けます。

## 動作条件とインストール

- Apple Silicon搭載Mac
- macOS 27.2以降
- モデルの取得に必要なインターネット接続と空き容量
- Web翻訳を利用する場合はGoogle Chrome

配布DMGを開き、`MyPLaMo for Mac.app` を右側の「Applications（アプリケーション）」へドラッグしてください。コピー完了後はDMGを取り出し、アプリケーションフォルダから起動します。使い方とライセンスはDMG内の「使い方とライセンス」フォルダに同梱しています。モデルは別途、アプリ内から取得します。

配布アプリにはDeveloper ID署名・Apple公証を行っていないため、macOSのセキュリティ機能によって起動が制限される場合があります。

## 用語集

翻訳画面の「用語集を管理…」から、分野や用途ごとの用語集を作成できます。用語ごとに原語・訳語・翻訳元言語・翻訳先言語を登録し、検索・編集・削除できます。翻訳画面の「用語集」で使用するものを選んでください。「用語集なし」も選べます。

翻訳方向が一致し、翻訳する文章に含まれる用語だけをモデルへの指示に使います。大文字・小文字は区別しません。用語集は訳語の採用を助けるもので、必ずその訳語になることを保証するものではありません。

用語集は100件、各5,000語まで登録できます。用語集名は80文字、原語・訳語はそれぞれ200文字までです。同じ翻訳方向で原語が重複する登録はできません。一度の翻訳部分に一致する用語が32語または原語・訳語の合計2,000文字を超える場合は、原文を短く分けてください。

### バックアップ・復元

用語集の管理画面の「バックアップ」で、**保存済みの全用語集**を `.myplamo-glossary` ファイルに保存できます。検索結果や選択中の1件に限定されません。編集中でまだ保存していない名前・用語は含まれないため、必要な変更は先に保存してください。用語が0語の用語集も保存できます。

「復元」でファイルを選ぶと、追加する用語集・用語の件数と、同じ内容のためスキップする件数を確認できます。「追加して復元」を押すまで現在のデータは変わりません。現在の用語集は残り、同じ名前でも内容が異なる場合は別の用語集として追加します。同じ内容を再び復元しても重複して増えません。翻訳に使用中の用語集は切り替わりません。

Windows版の同機能と共通の専用形式で、用語集名・原語・訳語・翻訳方向をまとめて保存します。ファイルの上限は128MiBで、展開後のデータも128MiB以下です。復元後も用語集100件・各5,000語の上限が適用されます。このファイルは暗号化されていません。手編集やCSVとしての読み込みには対応していません。

## 文脈を考慮した翻訳

「文脈を考慮」は初期状態でオンです。長い文章を分けて翻訳するときに、直前の原文・訳文を参考にして表現のつながりを保ちます。「参照する文脈」には、話題や文章の用途などを任意で800文字まで入力できます。

オフにすると、入力した参照文脈や直前の翻訳を追加せずに処理します。直前の原文・訳文は、1回の翻訳処理内だけで使います。

## Markdown・JSON・YAMLの翻訳

原文欄にテキストを貼り付け、「形式」で「自動判定」「テキスト」「Markdown」「JSON」「YAML」を選びます。自動判定が意図と異なる場合は、形式を指定してください。原文全体の上限は6,000文字です。

- **テキスト**：改行・段落・前後の空白を保ちながら翻訳します。
- **Markdown**：見出し・リスト・表などの文章を翻訳し、記法・コード・リンク先・先頭の設定部分（front matter）を保持します。
- **JSON**：自然言語を含む文字列の値を翻訳し、キー・数値・真偽値・URL・字下げなどを保持します。
- **YAML**：自然言語の値を翻訳し、キー・コメント・字下げ・型・URLなどを保持します。タグ・アンカー・エイリアス付きの値は変更しません。

JSON・YAMLを指定した場合、構文に問題がある入力はエラーとして案内します。文書の翻訳は完了後に元の構造へ組み立てて表示します。Word・PDF・画像のファイル読み込み機能ではありません。

## モデル

公式のPLaMo 3 Translate MLX-4bitモデルを使用します。

| モデル | ダウンロード容量の目安 |
| --- | --- |
| 0.8B | 約0.98 GB |
| 2B | 約2.41 GB |
| 8B | 約6.07 GB |
| 31B | 約18.66 GB |

実行時にはモデルの保存容量とは別にメモリが必要です。使用するMacのメモリ容量に合わせて選んでください。

保存先の変更、外部ドライブへの保存、ダウンロードの一時停止・再開、モデルの移動に対応します。ダウンロードしたファイルは整合性を確認してから使用します。

モデルは同時に1つだけ読み込みます。標準ではApple GPUを使用し、設定からCPUに切り替えられます。原文は1回6,000文字まで入力できます。翻訳結果が出力上限に達した場合は、文章を短く分けて翻訳してください。

モデルの利用条件は、ダウンロード画面のPLaMo Community Licenseを確認してください。

## ChromeでWeb翻訳

拡張2.3.6では、白ベースの設定メニューを刷新し、本文・操作項目の文字とツールバーのアイコンを見やすくしました。


Windows版MyPLaMoと共通の拡張機能「MyPLaMo ページ翻訳」を利用できます。本体で選択したモデル・GPUを使用し、言語・文体・用語集は拡張のメニューで設定できます。新しい設定機能にはMac本体0.3.0以降を使用してください。

### 拡張機能の追加

1. 本体を起動してモデルを選び、「Chromeからの翻訳を受け付ける」をオンにします。
2. 拡張機能の配布ZIPを展開します。
3. Chromeで `chrome://extensions` を開き、デベロッパーモードをオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」から、展開したフォルダ内の `extension` を選びます。リポジトリから取得した場合は `chrome/extension` を選んでください。
5. 翻訳するサイトへのアクセスを許可し、Webページを再読み込みします。

Mac版の受付スイッチは本体を起動するたびにオフになります。利用するときにオンにしてください。

### 翻訳・設定メニュー

ツールバーの拡張アイコンをクリックすると、翻訳・設定メニューが開きます。アイコンを押しただけではページ全体の翻訳は始まりません。

- **翻訳**：原語・訳語・用語集を選び、「このページを翻訳」または「原文に戻す」を押します。自動翻訳、原文ホバー表示、選択時の翻訳ボタン表示も設定できます。
- **自動翻訳フィルター**：自動翻訳するページ・サイトの除外リストや許可リストを管理します。手動翻訳には影響しません。自動翻訳は初期状態でオフです。
- **文体制御**：日本語訳の標準は「です・ます」です。「だ・である」にしたいページ・サイトを登録できます。
- **キャッシュ**：保存した翻訳をURLで検索し、ページ単位または全件を削除できます。
- **表示設定**：改行・折り返し、原文表示を閉じる動作、翻訳中の背景色を設定できます。

設定は自動保存されます。言語・用語集・文体を変更した場合は、再翻訳して反映してください。用語集の作成・編集はMac本体で行います。

### 選択した文章を翻訳

Webページの文章を選択し、そばに表示されるMyPLaMoアイコンをクリックすると、訳文のポップアップが開きます。上段に接続した本体のバージョンを表示します。右上のクリップボードアイコンで訳文をコピーでき、コピーするとチェックマークに変わります。×・Escape・ポップアップの外側のクリックで閉じられます。

言語・用語集・サイト別文体は拡張の設定に従います。1回の選択は2,000文字までです。文章を選択しただけでは翻訳を開始せず、ページ本文も書き換えません。入力欄や編集領域は対象外です。

### ページ全体を翻訳

メニューの「このページを翻訳」、またはページ上の右クリックから「MyPLaMoでWEB全体を翻訳」を選びます。本文・リンク・ボタン・後から追加された文章を翻訳します。ページ右下またはメニューの「原文に戻す」で元に戻せます。

原文ホバー表示をオンにすると、訳文の文字上にマウスを重ねたときに対応する原文を確認できます。PDF、画像内の文字、埋め込みフレーム、コード、入力欄、Chrome内部ページなどは対象外です。

### 更新と接続の案内

拡張を更新したら、拡張機能管理画面と翻訳したいWebページの両方を再読み込みしてください。

本体未起動または受付オフの場合は、拡張アイコンの右下に黄色い丸の「！」を表示します。未接続でも設定メニューは操作できます。接続状態は約1分ごとに加え、メニュー表示時や翻訳操作時にも確認します。

旧本体では基本の日本語翻訳を利用できますが、新しい言語・文体・用語集などの設定を使う場合は更新が必要です。互換性に関する案内が出た場合は、本体と拡張の両方を更新してください。

詳しくは [拡張機能のREADME](chrome/README.md) を参照してください。

## 設定とプライバシー

モデル取得後の翻訳はMac内で処理し、原文・訳文を外部の翻訳APIへ送信しません。モデル情報の取得とダウンロードにはHugging Faceへの通信を使用します。

履歴保存は初期状態でオフです。有効にすると最大100件を使用中のMacに保存します。設定から保存の無効化や履歴の削除ができます。

用語集と選択した用語集の設定はMac内に保存します。任意の参照文脈の本文は本体の設定や履歴には保存しません。翻訳中の直前ペアは1回の翻訳処理内だけで使い、次の翻訳依頼へ持ち越しません。

Chrome拡張の翻訳には、本体の起動と受付スイッチのオンが必要です。拡張からの翻訳で、本体の入力欄・翻訳結果・履歴は書き換えません。

拡張の設定と翻訳キャッシュはChromeのローカルストレージ（`storage.local`）に保存します。キャッシュには原文・訳文・参照文脈・ページURLを含みます。最大100ページ・約6MBで古いページから削除し、言語・文体・用語集・モデルなどが異なる結果は使い回しません。メニューの「キャッシュ」からページ単位または全件を削除できます。本体の履歴保存がオフでも、拡張のキャッシュは別に保存されます。
